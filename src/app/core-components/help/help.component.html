Help

There are various places within the tool that help text has been provided. In the setup wizard a help panel with details about each page can be opened and collapsed by clicking on the blue link.

Additionally, tooltips for certain input fields are provided next input labels. Hovering over the next to an input label will pop up some additional context for the input field.
