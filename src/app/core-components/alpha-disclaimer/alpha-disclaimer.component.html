Welcome to JUSTIFI!

Thank you for taking the time to test an alpha version of the JUSTIFI application. There are few things that you should take into consideration as you work your way through the tool:

  • The tool is a work in progress. You may encounter bugs along the way. Please use the feedback link to let the development team know what you have found. The more details that can be shared about the bug, the easier it will be for us to address them.
  • We will do our best not to break the data that is entered as we make updates to the application but it is possible updates cause breaking changes to existing data. The "Reset Database" button will purge the data in your system and allow you to start fresh.
