Welcome to JUSTIFI!

Thank you for taking the time to test an alpha version of the JUSTIFI application. There are a few things that you should take into consideration as you work your way through the tool:

  • The tool is a work in progress. You may encounter bugs along the way. Please use the feedback link to let the development team know what you have found. The more details that can be shared about the bug, the easier it will be for us to address them.
  • We will do our best to ensure compatibility and preserve existing data as we make updates to the application. However, please be aware that updates may occasionally result in breaking changes to existing data. If needed, the "Reset Database" button can be used to purge all the existing data and allow you to start fresh.
