Feedback

We'd love to hear from you! The JUSTIFI application is in active development and your feedback can drive the development decisions regarding user experience, new features and general content within the tool. The best way to provide feedback to the team is to email Kristina Armstrong (armstrongko@ornl.gov). This will allow the team to follow up with any clarification questions in a timely manner and update you on progress towards implementing your ideas!

Bug Reporting

If you happen to encounter a bug while using JUSTIFI please report them to Kristina Armstrong (armstrongko@ornl.gov) as well. She will help you get things sorted out and make sure we fix the bug so that no other users run into the same situation in the future.

Some details that are good to provide when reporting a bug include:

  • A .json backup of the data in your system (use the " Download Data" button)
  • Details of steps taken that triggered the bug you encounter that we can use to re-produce it
  • The type of browser you were using
  • Screen shots of what you are seeing/encountering
