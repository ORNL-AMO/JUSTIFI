Feedback & Support

We'd love to hear from you! The JUSTIFI application is in active development, and your input helps us improve the user experience, add features, and fix issues quickly. Please reach out to the JUSTIFI help desk at justifi-help@ornl.gov.

Feedback

Do you have suggestions for improving JUSTIFI? We welcome your ideas!

  • Send an email with subject line: “JUSTIFI Feedback - A Summary”
  • The team may follow up with you for clarification and updates.
Bug Reporting

If you encounter unexpected behavior, errors, or crashes:

  • Send an email with subject line: “JUSTIFI Bug Reporting - A Summary”
  • To help us resolve the issue faster, please include:
    • A .json backup file of the data (the " Download Backup Data" button) (if applicable)
    • Detailed steps to reproduce the bugs
    • The browser you were using
    • Screenshots (if possible)
Technical Support

For technical assistance, such as software installation, downloads, or troubleshooting:

  • Send an email with subject line: “JUSTIFI Technical Support - A Summary”
