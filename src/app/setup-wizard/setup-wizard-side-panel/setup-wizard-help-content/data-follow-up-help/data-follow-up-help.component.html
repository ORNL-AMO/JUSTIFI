The Review and Follow-up page provides a summary of the data collected during the assessment process.

A data summary table displays the total number of assessments, energy efficiency measures, and operational benefits that have been entered.

Items that have been flagged for follow-up actions are listed below the summary. Click on any flagged item to navigate directly to that entry for review and updates.

The Facility Protocol Questions section allows you to view, edit, and export the protocol questions for this facility. Click the link to open the questions page, or use the export button to download the questions to Excel.
