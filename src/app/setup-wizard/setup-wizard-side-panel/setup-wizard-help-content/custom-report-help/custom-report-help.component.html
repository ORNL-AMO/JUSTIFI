JUSTIFI automatically generates assessment and rollup reports for data evaluation. Users can also generate and save their own custom reports.

The Manage Reports page allows users to view all the reports within the selected visit, as well as add and delete reports.

Each custom report has options that a user can select to define the content of the report.

JUSTIFI has a built in set of report templates. The Report Type dropdown selects which report template to use for the custom report. Each template can then be modified to include whatever content a user chooses.
